## Release Discipline
- **v1.0.x**: Dedicated exclusively to bug fixes and security patches stemming from MVP release.
- **v1.1.x**: Minor feature releases addressing the highest priority real-world feedback from the admin Feedback Dashboard.
- **v2.0.0**: Major architectural enhancements (e.g., migrating to OpenAPI generated contracts, introducing message queues).

*Note: Features will remain in the Backlog until they are requested repeatedly in the User Feedback tracker.*
